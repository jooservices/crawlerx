# Source candidates for future adapters

**Vetted:** 2026-11-10

**Scope:** Public Japanese JAV and gravure catalogs. This document records discovery evidence only; it adds no adapters.

## Method and limits

The shortlist contains exactly 15 distinct source hosts absent from the absolute URL hosts in the 79 current adapter manifests (84 distinct manifest hosts). Each counted host has a readable `robots.txt`, one public server-rendered catalog/release response, and one successful linked work-detail response. I retained at most three direct GET responses per host, and spaced requests to each host by at least five seconds. Pages were read without login, browser automation, cookies, API keys, bulk crawling, or image downloads. Response headers and HTML were retained during vetting but are not committed.

The image notes describe work-specific elements and asset URLs in the detail HTML, not page-wide `<img>` totals. Package/jacket art and explicitly labeled sample stills are named only where the page identifies them. A work gallery without those labels remains untyped; this review does not infer which images are covers or samples. The pages rendered useful work fields without login. Age confirmation is noted where present.

A readable `robots.txt` with no AI-specific disallow means no AI-specific block was observed; it is not permission to reuse content. A `robots.txt` 404 means policy unknown and is excluded. Site terms and reuse licenses were not reviewed. Image and promotional-copy reuse risk is high for every source. **Build** means a metadata adapter is technically promising after terms and rights review; it does not authorize copying images, descriptions, or personal data. **Skip** means the source is not recommended for an adapter for the reason in that row. No image reuse is recommended without written permission or a clear license.

## Suggested follow-up

1. Start with a metadata-only adapter for a **Build** source after confirming the applicable terms and rights.
2. Model explicit package art, sample stills, and work-gallery images separately only where the response supports that distinction. Keep carousel-only images untyped.
3. Do not persist or redistribute covers, samples, or promotional text until written permission or a clear reuse license is established.
